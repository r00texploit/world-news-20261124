One editorial infographic of the world's news on **Tuesday 24 November 2026**: a lead story, five developments from
different regions and fields, a short "also today" list, original vector illustrations and compact source labels.
The program is offline and deterministic: it writes the committed `entry.png` to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## How it is built

- `design/page.html`: the layout, typography and inline SVG illustrations (no remote resources).
- `tools/render.mjs`: renders the page with a local headless Chrome at 1024×1024 and re-encodes the pixels as a PNG
  with no metadata (`tools/png.mjs`, standard library only), so the committed bytes depend only on the pixels.
- `main.ts`: checks the PNG against the gate limits and copies it to `/output/entry.png`.

## Checks

```sh
node --test                 # unit tests for the PNG tools and an end-to-end run of main.ts
node tools/verify.mjs       # whole-PNG check, <= 1024x1024, <= 1 MiB, two runs byte-identical
node tools/preview.mjs 300  # 300 px preview in build/, to check legibility
```
